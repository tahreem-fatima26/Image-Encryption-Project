# Image Encryption Project

This project demonstrates a simple image encryption and decryption tool using Python and Pillow (PIL).

## Features
- Image Encryption
- Image Decryption
- Pixel Manipulation
- PNG Image Support

## Technologies Used
- Python
- Pillow (PIL)

## Project Files
- Image_Encryption.py
- input.png
- encrypted.png
- decrypted.png
